# Rédaction Via Citadina
- Message : rejet du Sénat → on ne se résigne pas → on construit un projet de société.
- Ton : digne, exigeant, tourné vers l'avenir, inclusif (« nous »).
- Structure du manifeste : constat → leçon → idée centrale (l'autonomie = projet, pas
  seulement un statut) → appel à agir localement → appel à contribuer sur le site.
- Appels à l'action : « Je contribue », « Je rejoins la démarche ».
- Questions clés à mettre en avant : « Que voudriez-vous pour la Corse de demain ?
  Quelles propositions ? Comment les concrétiser ? »
- Respecter la typographie française (espaces insécables avant : ; ! ?, guillemets « »).
- Proposer une version en langue corse sur demande, à faire relire par un locuteur.
