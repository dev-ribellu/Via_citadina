# SEO & accessibilité
- Balises : title, meta description, lang="fr", canonical, Open Graph + Twitter card
  (image 1200x630 avec logo), favicon (tour rouge).
- Un seul h1, hiérarchie propre, alt sur images, labels liés aux champs,
  aria-live pour le message de succès/erreur.
- Contraste ≥ 4.5:1, focus visible, formulaire utilisable au clavier.
- Performance : images WebP, polices auto-hébergées, Lighthouse > 90.
- sitemap.xml, robots.txt.
