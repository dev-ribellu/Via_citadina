# Design system Via Citadina
- Palette (variables Tailwind) : rouge #E8202A, rose #D6246E, orange #EE7A1B,
  jaune #F5A81C, vert-clair #7AB929, vert #1FA83C, encre #1A1A1A, fond #FFFFFF.
- Dégradé signature : `linear-gradient(90deg,#C8203C,#D6246E,#EE7A1B,#F5A81C,#7AB929,#1FA83C)`
  utilisé en filet sous les titres, bordures de boutons, séparateurs.
- Bouton principal : fond rouge #E8202A, texte blanc, arrondi 12px, hover plus sombre.
- Titres : Poppins 700-800, majuscules possibles pour le hero.
- Sections alternées blanc / gris très clair #FAF7F5.
- Vérifier contraste AA (le jaune ne sert jamais de texte sur blanc).
- Logo : toujours sur fond blanc/clair, marge de protection = hauteur de la tour/4.
